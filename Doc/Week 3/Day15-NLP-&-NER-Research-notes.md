Today, I will be learning about NLP and NER.

What is NLP? NLP stands for Natural Language Processing, which deals with unstructured text. The fundamental concept involves transforming unstructured data into structured data so that machines can comprehend the information contained within. NLP bridges the gap between humans—who use unstructured language—and machines—which operate using structured data. Since user requests are unstructured while machines only understand structured data, NLP plays a crucial role here. Common subfields of NLP include NLU (Natural Language Understanding) and NLG (Natural Language Generation). NLU is used to process unstructured client requests into structured data so the machine understands the required action. Conversely, NLG converts structured data (the machine's response) into an unstructured format that the client can understand. Real-world applications of these concepts include tools such as machine translators, virtual assistants (chatbots), sentiment analysis (detecting serious or sarcastic sentiment), and spam detection. Because user or client input is unstructured, various NLP algorithms are employed for processing. One of the initial steps is tokenization. Tokenization involves breaking text down into units called tokens; for instance, the sentence "Hi my name is HAN" consists of five words, resulting in five tokens. Following tokenization, the next stages are stemming and lemmatization. Stemming involves grouping various word forms—such as "run," "running," and "ran"—under a single base form: "run." The reason for this is that "run" is the base form (verb-1/present tense), "ran" is the past tense (verb-2), and "running" is the continuous form (verb-ing). Consequently, whether the input is "I'm running now" or "I ran yesterday," the system can recognize "run" as the underlying base form. The principle of _stemming_ involves stripping away affixes (prefixes or suffixes) to derive the root word from the data. However, _stemming_ has a limitation when dealing with different words that share the same root; for instance, the words "universal" and "university" might not be correctly recognized if only _stemming_ is used. Therefore, _lemmatization_ is required in certain situations. Unlike _stemming_, _lemmatization_ does not merely seek the root word but analyzes the word type within a specific context; the system performs a deeper analysis if _stemming_ fails to recognize the word. Both _stemming_ and _lemmatization_ are processes that occur after tokenization. The next stage is _Part-of-Speech (POS) tagging_. This concept involves identifying word types within a sentence based on context. For example, in the sentence "I'm going to make dinner," the system recognizes "make" as a verb. Conversely, in the sentence "What is the make of your laptop?", the system recognizes "make" as a noun. The final stage is NER, or _Named Entity Recognition_.

What is NER? NER is a technique used to classify _Named Entities_ within unstructured text. NER can detect entities such as people's names and locations; consequently, the system can easily identify names of people, organizations, dates, times, monetary values, geopolitical entities (GPE), and locations within a text.

What is the difference between Regex and NER? Regex (_Regular Expression_) operates based on predefined patterns. These patterns are simple, making Regex effective for detecting uncomplicated conditions. Regex is frequently implemented for formats with fixed patterns, such as email addresses (username@domain.extension), phone numbers (numeric only), dates (which vary by country-specific rules), and identification numbers (e.g., unique hospital ID formats). In contrast, NER excels at detecting more complex entities, such as people's names, organizations, dates, times, monetary values, GPEs, and locations.
